# CSHM-Diffusion-Model
This diffusion model is based on the physics of coupled stochastic harmonic oscillators. Each oscillator represents a distint diffusion task and the couple springs represent their shared information. This model is able to handle N diffusion tasks by modeling them as N coupled oscillators. 

The model was tested on the common task of generating images and labeling them. We then tested it's ability to generate the images and label them.
